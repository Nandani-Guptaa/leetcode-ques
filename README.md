## 💡 Approach

I try to focus not only on getting an accepted solution, but also on understanding:

1. **Why the solution works**
2. The underlying pattern
3. Time complexity
4. Space complexity
5. Possible optimizations
6. Edge cases
7. Alternative approaches when useful

The goal is to develop the ability to recognize **patterns**, rather than memorizing individual solutions.
